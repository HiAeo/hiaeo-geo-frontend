## 4. 部署说明

### 4.1 Vercel 部署注意

⚠️ **重要：Vercel Serverless 限制**

Vercel 的 Serverless 环境**不支持原生 Node.js 模块**，以下模块在部署时需要特殊处理：

| 模块 | 替代方案 |
|------|---------|
| `better-sqlite3` | ❌ 不支持，使用 JS 实现或云数据库 |
| `sqlite3` | ❌ 不支持，使用 JS 实现或云数据库 |
| `bcrypt` | ✅ 可用，但优先使用 `bcryptjs` |
| `bcryptjs` | ✅ 纯 JS，支持 |
| `sharp` (图片处理) | ❌ 不支持，使用云函数/外部服务 |

**当前解决方案：**
- 创建轻量级 `api/index.js` 作为 Vercel API Handler
- 绕过 NestJS 构建，直接处理请求
- 使用内存存储或外部服务进行数据持久化

### 4.2 本地开发

```bash
# 前端
cd hiaeo-geo-frontend
npm install
npm run dev

# 后端
cd hiaeo-backend
npm install
npm run start:dev
```

### 4.3 环境变量

**前端 (.env.development):**
```env
VITE_API_BASE_URL=http://localhost:3000/api
```

**前端 (.env.production):**
```env
VITE_API_BASE_URL=https://hiaeo-geo-backend.vercel.app/api
```

**后端 (.env):**
```env
# 数据库
DATABASE_URL=mysql://user:password@localhost:3306/hiaeo

# Redis
REDIS_URL=redis://localhost:6379

# AI 服务
OPENAI_API_KEY=sk-...
ANTHROPIC_API_KEY=sk-ant-...
GOOGLE_AI_API_KEY=...

# JWT
JWT_SECRET=your-jwt-secret

# 支付宝
ALIPAY_APP_ID=...
ALIPAY_PRIVATE_KEY=...
ALIPAY_PUBLIC_KEY=...

# 向量数据库
MILVUS_URI=http://localhost:19530
PINECONE_API_KEY=...
```
