## 1. 产品概述

### 1.1 产品定位

**魔鲸 Geo (ModelBuddy)** - 品牌可见度智能分析平台

通过 AI 技术帮助品牌诊断和优化在 AI 搜索引擎（如 Perplexity、ChatGPT）中的可见度，让 GEO（Generative Engine Optimization）像呼吸一样简单。

### 1.2 核心价值

- **模镜 MiraSeek** - AI 可见度诊断，洞察品牌在 AI 搜索中的表现
- **模豆 MiraMod** - GEO 智能策略生成，提供可执行的优化建议
- **模法 MiraMag** - AI 内容创作，自动化生成合规品牌内容
- **协同驾驶舱** - 团队协作管理，三角色视图（老板/运营/技术）

## 4. 数据流

### 4.1 用户登录流程

```
用户输入邮箱密码
       │
       ▼
前端 POST /api/auth/login
       │
       ▼
后端 AuthModule 验证凭证
       │
       ├─── 成功 ───→ 生成 JWT Token
       │              │
       │              ▼
       │         返回 { accessToken, refreshToken, user }
       │
       └─── 失败 ───→ 返回 401 错误
```

### 4.2 AI 诊断流程

```
用户提交品牌 URL
       │
       ▼
前端 POST /api/v1/diagnosis/run
       │
       ▼
后端 DiagnosisModule
       │
       ├─── 抓取网页内容
       ├─── 调用 AI 引擎分析
       ├─── 计算可见度评分
       └─── 返回诊断报告
       │
       ▼
前端展示诊断结果
```

### 4.3 知识库检索流程

```
用户搜索查询
       │
       ▼
前端 POST /api/v1/knowledge/search
       │
       ▼
后端 KnowledgeModule
       │
       ├─── 将查询向量化
       ├─── 向量数据库相似度搜索
       ├─── 返回相关知识条目
       └─── AI 增强结果
       │
       ▼
前端展示搜索结果
```

## 5. 安全架构

### 5.1 认证机制

- **JWT Token** - 访问令牌（15分钟有效期）
- **Refresh Token** - 刷新令牌（7天有效期）
- **角色权限** - brand（品牌用户）/ admin（管理员）

### 5.2 API 安全

- CORS 配置限制允许的来源
- Rate Limiting 限流保护
- Helmet 安全头部
- 输入验证（class-validator）
