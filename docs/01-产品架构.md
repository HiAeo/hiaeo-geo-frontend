## 1. 产品概述

### 1.1 产品定位

**魔鲸 Geo (ModelBuddy)** - 品牌可见度智能分析平台

通过 AI 技术帮助品牌诊断和优化在 AI 搜索引擎（如 Perplexity、ChatGPT）中的可见度，让 GEO（Generative Engine Optimization）像呼吸一样简单。

### 1.2 核心价值

- **模镜 MiraSeek** - AI 可见度诊断，洞察品牌在 AI 搜索中的表现
- **模豆 MiraMod** - GEO 智能策略生成，提供可执行的优化建议
- **模法 MiraMag** - AI 内容创作，自动化生成合规品牌内容
- **魔鲸 Hub** - 品牌 GEO 控制中心，数据中枢与调度中心

### 1.3 产品愿景

**"输入网址，获得持续 AI 增长引擎"**

用户只需在首次填入网址 + 点击几下"下一步"，后续系统会像自动驾驶一样自我迭代。

## 3. 用户操作流（仅需 3 步主动操作）

### 步骤 1：输入网址 → AI 完成 80% 填写
- 用户进入品牌智库，粘贴官网 URL，点击"AI 智能预填"
- Agent 自动抓取官网内容，生成结构化建议
- 用户只需检查、补全个别细节，提交后知识库自动保存

### 步骤 2：一键开启闭环循环
1. 点击"开始 AI 诊断" → 自动触发模镜诊断，生成 7 维健康分
2. 诊断完成后，点击"生成 GEO 策略" → 模豆基于诊断结果生成策略列表
3. 策略确认后，点击"一键执行优化" → 模法批量生成内容

### 步骤 3：监控看板自动循环
- 执行完毕后，用户切换到"品牌监控"视图
- 系统会**自动定时重新诊断**，并将结果反馈给 Agent
- Agent 分析变化后建议新一轮策略，用户可一键采纳继续优化

## 4. 模块联动逻辑（以 Agent 为大脑）

| 环节 | 触发方式 | AI Agent 职责 |
|------|---------|--------------|
| 智库填充 | 手动点击"AI 预填" | 爬取官网 HTML/Meta/文本，生成结构化建议 |
| 诊断 | 手动点击"开始诊断" | 读取知识库 + 向量检索，计算 7 维得分 |
| 策略生成 | 手动点击"生成策略" | 将诊断报告薄弱项 + 知识库注入 Prompt，生成策略 |
| 执行 | 手动点击"一键执行" | 按策略模板生成内容，自动发布草稿 |
| 监控与闭环 | 自动定时（每日/实时） | 定期触发诊断，发现下降时生成预警和优化建议 |

## 5. 工作流状态机

### 5.1 状态定义

| 模块 | 状态 | 说明 |
|-----|------|-----|
| 知识库 | DRAFT → PROCESSING → COMPLETED | 知识库完善流程 |
| 诊断 | DRAFT → READY → PROCESSING → COMPLETED / ERROR | AI 诊断流程 |
| 策略 | DRAFT → READY → PROCESSING → COMPLETED / ERROR | 策略生成流程 |
| 执行 | DRAFT → READY → PROCESSING → COMPLETED / ERROR | 内容执行流程 |
| 监控 | DRAFT → READY → COMPLETED | 监控启用 |

### 5.2 状态联动规则

```
知识库 COMPLETED → 诊断按钮可点击（READY）
诊断 COMPLETED → 策略按钮可点击（READY）
策略 COMPLETED → 执行按钮可点击（READY）
执行 COMPLETED → 监控视图可查看（READY）
```

### 5.3 workflow_state 数据结构

```json

}
```
