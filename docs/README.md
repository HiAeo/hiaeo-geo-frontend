## 📝 文档维护规则

### 何时更新文档

| 情况 | 需要更新的文档 |
|------|---------------|
| 新增功能模块 | 01-产品架构、03-开发进度追踪 |
| 技术栈变更 | 02-技术栈说明 |
| 架构决策 | 04-关键设计决策记录 |
| 版本发布 | 03-开发进度追踪 |
| 解决已知问题 | 03-开发进度追踪 |

### 提交规范

```bash
# 文档更新也需要提交
git add docs/
git commit -m "docs: 更新 XX 文档"

```

## 🤖 AI 助手使用指南

### 首次对话

每次新的对话开始时，告诉 CodeBuddy：

```
请先阅读 docs/ 目录下的文档，了解项目背景和当前状态。
```

### 遇到问题时

1. 先查阅 [03-开发进度追踪](./03-开发进度追踪.md) 中的「已知问题」
2. 查看 [04-关键设计决策记录](./04-关键设计决策记录.md) 了解相关决策背景
3. 参考 [02-技术栈说明](./02-技术栈说明.md) 了解技术细节
